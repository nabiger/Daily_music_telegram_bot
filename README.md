# 🎧 Daily Music Telegram Bot

یک ربات تلگرام هوشمند و مدرن مبتنی بر **Python** و **aiogram 3** برای ارسال روزانه موزیک و دریافت پیشنهادات از کاربران.

این پروژه به گونه‌ای طراحی شده که بدون اشغال فضای ذخیره‌سازی سرور، متادیتای صوتی و کاور اصلی فایل‌ها را کاملاً حفظ کرده و قابلیت اجرا روی پلتفرم‌های ابری رایگان مثل **pythonanywhere** یا **justrunmy.app** را داراست.

---

## ✨ ویژگی‌های کلیدی

* 🎵 **حفظ کامل متادیتا:** ذخیره بر اساس `file_id` تلگرام جهت حفظ ۱۰۰٪ کیفیت، کاور اصلی، نام خواننده و تگ‌های صوتی.
* ⏰ **ارسال خودکار روزانه:** زمان‌بندی دقیق ارسال موزیک با استفاده از `APScheduler`.
* 💡 **سیستم پیشنهاد موزیک (FSM):** امکان ارسال موزیک، وویس یا متن توسط کاربران برای ادمین.
* ⚡ **سرعت بالا و حجم صفر:** عدم نیاز به دانلود و آپلود مجدد فایل‌ها روی سرور.

---


* **Python 3.10+**
* **aiogram 3.x**
* **APScheduler**
* **aiohttp**
